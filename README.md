# Giacomino

## Run Locally

Install dependencies:

```sh
pnpm install
```

Start the development server:

```sh
pnpm run dev
```

Open the app at:

```text
http://localhost:5173
```

The Vite server is configured to use port `5173` exactly, so stop anything already using that port before starting it.

## Production Build

Build the app:

```sh
pnpm run build
```

Preview the production build:

```sh
pnpm run preview
```
